# Metagel Simulator · 元凝胶超声传感交互演示

基于 **Tang H. et al. "Injectable ultrasonic sensor for wireless monitoring of intracranial signals." *Nature* 630, 84–90 (2024)**（DOI: [10.1038/s41586-024-07334-y](https://doi.org/10.1038/s41586-024-07334-y)）的可注射元凝胶（metagel）传感器**理想化交互仿真**，用于直观理解其传感机制：

> 环境参数变化 → 水凝胶形变 → 周期空气柱晶格常数改变 → 声子带隙移动 → 超声反射峰频移 → 多配方并读解耦

## 打开即用

GitHub Pages 在线访问：**https://tonalinohitsuzi.github.io/metagel-simulator/**

或本地双击 `index.html`（Three.js 经 CDN 加载，需联网）。

## 演示内容

| 模块 | 说明 |
|---|---|
| **3D 构象** | 纯代码建模的 2×2×2 mm 元凝胶（半透明基质 + 5×5×5 周期空气柱）；拖动旋转、滚轮缩放 |
| **三参数滑块** | 压力 0–70 mmHg（压缩）、温度 28–43 °C（PNIPAM 温缩）、pH 8→2（壳聚糖酸胀） |
| **反射谱面板** | 三种配方凝胶并读，峰位按论文标定参数实时漂移，可叠加模拟测量噪声 |
| **解耦反演** | 从三路含噪频移经 3×3 矩阵求逆反演出 P/T/pH，与真值对照——"定向放大 + 解耦"一眼看懂 |
| **一键剧本** | 只变压 / 只升温 / 只变 pH / 混合扰动，观察各凝胶的选择性响应 |

## 数值内核（忠于论文标定）

| 凝胶 | f₀ | 主灵敏度（相对频移斜率） | 出处 |
|---|---|---|---|
| 压力（PVA/CMC） | 8.98 MHz | 6.343×10⁻⁴ /mmHg（≈5.7 kHz/mmHg） | Fig. 2f |
| 温度（PVA/PNIPAM） | 8.42 MHz | 0.0095 /°C（≈80 kHz/°C） | Fig. 2h |
| pH（PVA/壳聚糖） | 9.47 MHz | 0.02708 /pH（≈256.4 kHz/pH） | Fig. 2j |

**简化假设（诚实声明）**：三凝胶对非目标参数的交叉灵敏度论文未公布数值，本演示设为近零理想值；论文原口径为"效应独立且近线性，两支凝胶同步测量即可解耦"，本页采用 3×3 反演仅为教学直观；反射谱画为示意高斯峰，非实测谱形；3D 形变为概念化映射，非有限元结果。

## 相关复现

论文开源 MATLAB 信号处理代码（门控 → 10 帧叠加 → 零填充 FFT → 包络 → 自适应峰位追踪）的本地复现记录：谱分辨率 ≈45.3 Hz，示例 pH 会话数据峰位漂移 +50.2 kHz。

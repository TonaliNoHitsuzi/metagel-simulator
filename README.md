# Metagel Simulator · 元凝胶超声传感测量闭环演示

基于 **Tang H. et al. "Injectable ultrasonic sensor for wireless monitoring of intracranial signals." *Nature* 630, 84–90 (2024)**（DOI: [10.1038/s41586-024-07334-y](https://doi.org/10.1038/s41586-024-07334-y)）的可注射元凝胶（metagel）传感器**测量闭环交互仿真**——不是把答案画给你看，而是走完仪器真实经历的每一步：

> 参数（隐藏真值）→ 原始回波 r(t)（唯一可测）→ 解调管线 → 反射谱 |R(f)| → 峰位 → 校零 → 矩阵反演 → 参数估计

## 演示剧本

「随机变压 / 随机变温 / 随机变 pH / 混合扰动」均为**相对当前状态的随机增量**（非绝对跳变；混合=三参数同时随机），复位回到默认态（10 mmHg / 37 °C / 7.4）。

## 模拟方法声明

本页全部信号为浏览器内数值模拟（无实测采集），页面底部模拟方法与数据声明折叠块写明完整链条：传感模型（论文标定主灵敏度 + 演示设定交叉项）→ 窄带回波合成（半余弦门控包络、确定性初相、高斯白噪声）→ 解调管线（与论文开源 MATLAB 代码同构）→ 基线校零 → 3×3 反演，并列出与实测的主要差距。

## 测量闭环四步

| 步骤 | 内容 |
|---|---|
| **① 原始信号** | 三通道门控回波 r(t) 实时刷新（窄带回波模型：峰频=载频，帧间相位确定、噪声随机）——参数变了只能看到波形微变，看不到答案 |
| **② 解调管线** | 点击"运算"，五步依次点亮：门控截取 → 10 帧叠加（压噪 √10）→ 零填充 FFT（16384 点）→ 滑动峰值包络 → 峰位追踪（+抛物线插值），忠实论文开源 MATLAB 代码结构 |
| **③ 解调谱** | 谱形由信号现场算出（非预画）：灰色毛刺=原始幅度谱，青色=包络，红线=峰位 |
| **④ 反演** | 先以无噪基线解调做**仪器校零**（吸收窗/包络系统偏置），再解 3×3 线性方程组得 P/T/pH 估计，与真值对照 |

参数变化后谱面板自动标记"数据过期"，须重新运算——测量不是免费的。

## 数值内核（忠于论文标定）

| 凝胶 | f₀ | 压力 kP | 自身灵敏度 | 通道信号含义 |
|---|---|---|---|---|
| 压力（PVA/CMC） | 8.98 MHz | **6.343×10⁻⁴**/mmHg（≈5.7 kHz/mmHg，Fig. 2f） | –（惰性基质） | 纯压力 |
| 温度（PVA/PNIPAM） | 8.42 MHz | 4.5×10⁻⁴（演示设定） | 0.0095/°C（≈80 kHz/°C，Fig. 2h） | **压力+温度混叠** |
| pH（PVA/壳聚糖） | 9.47 MHz | 3.5×10⁻⁴（演示设定） | 0.02708/pH（≈256.4 kHz/pH，Fig. 2j） | **压力+pH 混叠** |

耦合结构忠于论文物理：压力是力学量，三支凝胶的空气柱同时被压缩（三通道一起动）；温度/pH 是化学刺激，仅含响应组分的凝胶显著响应（选择性）。系数矩阵为下三角——压力凝胶单独定 ΔP，其余扣除压力贡献后各定各的，即论文两支凝胶即可解耦的级联。

默认噪声档反演误差 ~0.2 mmHg / 0.01 °C / 0.002 pH；**调大噪声滑块再运算，误差显著恶化**——信噪比的代价可视化。

## 简化假设（诚实声明）

三凝胶交叉灵敏度论文未公布数值，设为近零理想值；论文原口径"效应独立近线性，两支凝胶即可解耦"，本页用 3×3 反演为教学强化；回波用窄带模型（真实带隙反射谱形更复杂）；3D 形变为概念映射，非有限元结果。

## 相关复现

论文开源 MATLAB 信号处理代码本地复现（R2021b）：修正开源代码 `num_rec` 越界 bug 后跑通，pH 会话 198 帧峰位漂移 +50.2 kHz，谱分辨率 45.3 Hz——管线结构与本页 ② 完全一致。
